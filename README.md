# Shark Tank India Investment Analysis

## 📌 Overview
This repository contains my internship project analyzing Shark Tank India data.  
The project involved downloading a dataset, cleaning it using **Jupyter Notebook (Python & Pandas)**, and creating dashboards in **Tableau Public**.  
It also includes a text summary file highlighting **Founder Success Patterns**.

---

## 📊 Project Workflow
1. **Dataset Downloaded**  
   - Raw Shark Tank India dataset with missing values, duplicates, and inconsistent formats.  

2. **Data Cleaning in Jupyter Notebook**  
   - Handled missing values, removed duplicates, and converted datatypes.  
   - Tools used: Python, Pandas.  

3. **Tableau Dashboards**  
   - Created sheets and dashboards showing:  
     - Funding Outcomes  
     - Investor Participation  
     - Valuation vs Deal Amount  
     - Equity Trends  
     - Industry Insights  

4. **Summary File**  
   - `Founder_Success_Pattern_Summary.txt` explains the patterns of successful founders.  
   - Key takeaway: Flexibility in valuation, balanced equity offers, and clear pitch communication drove success.  

---

## 🧠 Learning Note
I also learned **SQL basics** (SELECT, JOIN, GROUP BY, AVG, importing datasets).  
However, in this project, SQL was **not used** — the focus was on Python (Pandas) for data cleaning and Tableau for visualization.  

---

## 📄 Conclusion
This project demonstrates how data cleaning and visualization can uncover meaningful insights into startup funding trends.  
Founder success was strongly linked to adaptability in valuation, balanced equity offers, and operating in scalable industries.
